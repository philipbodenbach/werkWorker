Local agent engine · Rust

Connect models to tools.

werkWorker turns model responses into actions in your workspace. An interactive terminal and an embeddable Rust SDK share the same agent engine, with explicit permissions and persistent sessions.

werkWorker + Werk1112

One engine. Terminal and SDK.

Werk1112 handles inference and model runtimes. werkWorker handles the conversation, tools and the lifecycle of a task.

Interactive terminal

Stream responses, steer a running task and review tool approvals from the terminal. The short command is ww.

Tools with explicit permissions

Resource grants and prepared-action approvals control access. File and process isolation currently requires Linux.

Persistent sessions

SQLite-backed sessions record events and support follow-ups, cancellation and recovery. Embed the engine through Rust or use the JSONL protocol.

Quick start

Try the terminal locally.

Build from the repository with Rust 1.88 or newer. The demo runs offline; connect your Werk server for real model calls.

Installation and releases ↗Connect a Werk server ↗
git clone https://github.com/philipbodenbach/werkWorker.git
cd werkWorker
cargo install --path . --locked
ww tui --demo "Hello"
ww --help

Both ww and werk-worker are installed. The offline demo uses scripted responses, not a live model.
