# CLI reference

Generated by `scripts/generate-cli-reference.py`. `ww` exposes the same commands.

## werk-worker

```text
werkWorker general-purpose local agent engine

Usage: ww [OPTIONS] [COMMAND]

Commands:
  tmp       Inspect and remove old WerkWorker temporary files [alias: temp]
  cache     Inspect and remove build files, backups and explicitly selected shared caches
  tui       Interactive agent UI (the default when no command is supplied)
  run
  resume
  sessions
  tools
  skills
  profiles
  sandbox
  diagnose
  rpc
  help      Print this message or the help of the given subcommand(s)

Options:
      --setup
          Open the interactive connection setup, even with an explicit configuration
      --store <STORE>

      --workspace <WORKSPACE>
          [default: .]
      --grants <GRANTS>

      --execution-config <EXECUTION_CONFIG>
          Host-owned inference and subagent limits JSON
      --continuous
          Run without aggregate step/request/time cutoffs (default in interactive mode)
      --limits <LIMITS>
          Explicit run budgets JSON; overrides the interactive continuous default
      --harness-config <HARNESS_CONFIG>
          Optional completion criteria and explicit host guidance JSON
      --bubblewrap <BUBBLEWRAP>
          Bubblewrap executable; defaults to the system or per-user installation
      --native-sandbox-config <NATIVE_SANDBOX_CONFIG>
          Trusted native sandbox configuration JSON; never read from the workspace
      --process-limits <PROCESS_LIMITS>
          Trusted process resource limits JSON, separate from agent run budgets
      --werk-config <WERK_CONFIG>
          Explicit Werk transport/model configuration JSON; no credentials inside
      --secret-env <SECRET_ENV>

      --script <SCRIPT>
          Explicit deterministic offline responses, never a provider fallback
  -h, --help
          Print help
  -V, --version
          Print version
```

  list   List owned WerkWorker entries in the system temporary directory

## tmp purge

```text
Remove one listed ID or all eligible WerkWorker temporary entries

Usage: ww tmp purge [OPTIONS] [ID]

Arguments:
  [ID]  Exact ID printed by list; paths and wildcards are not accepted

Options:
      --all                                  Select all eligible entries in the requested scope
      --dry-run                              Show what would be removed without deleting anything
      --json
      --older-than-hours <OLDER_THAN_HOURS>  [default: 24]
  -h, --help                                 Print help
```
